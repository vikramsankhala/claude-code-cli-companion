# Acceptable use: AI services in this course (template)

Edit the bracketed parts for your course and hand this out in session 1.

**Course:** [name] · **Instructor:** [name] · **Services:** NVIDIA API catalogue (build.nvidia.com) and [others]

1. **Learning only.** Use these services for coursework, labs and practice projects. Do not use them for paid work, client work, a live service or anything in production. NVIDIA's free catalogue is licensed for development, testing, research and evaluation; production needs a separate licence.
2. **Your own account and key.** Register with your own email. Never share, borrow or publish a key. A submission that contains a key fails the key-handling criterion.
3. **Safe data only.** Use the course datasets or public data. Never send personal data (yours or anyone else's), client data, passwords or confidential documents.
4. **Model licences.** Each model has its own licence (for example the Llama community licence). Read the model card before you use a model in a project, and credit the model in your report.
5. **Fair use of limits.** Limits are per account. Do not write loops that hammer the service; use the course scripts, which slow down and retry.
6. **Honesty.** You may use AI tools where the assignment allows. Say which tools and models you used and for what, and be ready to explain every line you submit.
7. **Reporting.** If you see harmful output or a security problem, stop and tell the instructor.
